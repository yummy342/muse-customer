# Muse助手 · 客户版

Windows 桌面小工具：用店主提供的平台邮箱登录，自动连接美国出口通道，
在浏览器里打开 [muse.ai](https://muse.ai/)；Muse / Meta 的验证码邮件会自动
盯收，码到了直接复制粘贴。

## 下载

- https://aiglade.cn/dl/muse-customer-exe-20261024.zip

GitHub 备用（大陆网络有时连不上）：

- 本仓库里点 [release/muse-customer-exe-20261024.zip](release/muse-customer-exe-20261024.zip) → 右侧「Download raw file」；
- 或到 [Releases](../../releases/latest) 页下载同一份。

解压到**空文件夹**再运行。

- 适用系统：Windows 10 / 11（64 位）
- 免安装、不需要 Python

## 使用

1. 双击 `Muse助手.exe`。
2. 输入店主给你的**平台邮箱**和密码，点「登录」。
3. 登录成功后通道自动连接；看到绿灯，点「① 打开 muse.ai」。
4. 在网页里填邮箱时点「② 复制邮箱」；验证码到了点「复制验证码」粘贴。

首次使用前，请把店主单独发给你的两个文件放到 exe 同目录（或
`%USERPROFILE%\.muse-assistant\`）：

- `egress-auth.json` —— 你的出口身份
- `muse_hop_key` —— 连通道用的受限私钥

> 不要把整个 `.muse-assistant` 文件夹拷过来 —— 里面可能混着别人的凭据。

## 常见问题

**双击没反应 / 被 SmartScreen 拦住**
本程序未做代码签名，Windows 会提示「未知发布者」。点「更多信息 → 仍要运行」。
如果仍被拦截，检查杀毒软件是否隔离了文件。

**「连不上邮箱服务器」**
先确认网络正常。一直连不上就联系店主。

**「密码不对」**
和店主给你的那串逐字核对（注意大小写和空格）。忘了请店主重置。

**「通道连不上」**
点「重新连接」。还不行，把界面上的提示原文发给店主。

**窗口不见了**
点 ✕ 是收进系统托盘，不是退出。双击托盘里的 Muse助手图标即可找回；
真退出请右键托盘图标选「退出」。

## 安全与隐私

- 密码用 Windows DPAPI 加密后保存在本机用户目录，**只有本机、本 Windows
  账号能解开**；文件拷到别的电脑上无效。
- 程序目录里不会保存你的密码。
- 卸载：删除程序文件夹即可；要清掉密码，再删
  `%LOCALAPPDATA%\MuseAssistant\`。
